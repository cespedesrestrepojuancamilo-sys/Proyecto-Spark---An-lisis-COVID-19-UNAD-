Este proyecto realiza un procesamiento batch utilizando **Apache Spark** con **PySpark**.  
El conjunto de datos COVID-19 fue obtenido del portal [datos.gov.co](https://www.datos.gov.co/).  
El objetivo es limpiar, transformar y analizar los registros para identificar patrones relacionados con la edad, el estado y el departamento de los casos reportados.
